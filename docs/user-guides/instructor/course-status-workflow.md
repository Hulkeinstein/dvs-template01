# Course Status Workflow

코스의 상태 전환 및 각 상태별 가능한 액션을 설명합니다.

## 상태 다이어그램

```
┌─────────┐   Submit for   ┌─────────┐    Approve    ┌───────────┐
│  Draft  │ ─────────────▶ │ Pending │ ───────────▶ │ Published │
└─────────┘    Review      └─────────┘               └───────────┘
     ▲                          │                         │
     │                          │ Reject                  │
     │                          ▼                         │
     │                    ┌──────────┐                    │
     │    Resubmit        │ Rejected │                    │
     │    ┌───────────────┴──────────┘                    │
     │    │                                               │
     │    ▼                                               │
     └────┴───────────────────────────────────────────────┘
                         Unpublish
```

## 상태 설명

| 상태 | 설명 | 학생 노출 | 수정 가능 |
|------|------|----------|----------|
| **Draft** | 작성 중인 코스. 자유롭게 수정 가능 | ❌ | ✅ |
| **Pending** | 관리자 승인 대기 중 | ❌ | ❌ |
| **Published** | 승인 완료. 학생에게 공개됨 | ✅ | ❌ |
| **Rejected** | 관리자가 반려. 수정 후 재제출 필요 | ❌ | ✅ |

## 상태별 가능한 액션

### Draft (초안)

| 액션 | 설명 |
|------|------|
| ✅ 코스 정보 수정 | 제목, 설명, 가격, 썸네일 등 |
| ✅ 레슨 추가/수정/삭제 | 모든 레슨 관리 가능 |
| ✅ 퀴즈 추가/수정/삭제 | 모든 퀴즈 관리 가능 |
| ✅ Submit for Review | 관리자 승인 요청 |
| ✅ Delete | 코스 삭제 |
| ❌ 학생 등록 | 공개 전이므로 불가 |

### Pending (승인 대기)

| 액션 | 설명 |
|------|------|
| ❌ 코스 정보 수정 | 승인 대기 중 수정 불가 |
| ❌ 레슨 추가/수정/삭제 | 승인 대기 중 수정 불가 |
| ❌ 퀴즈 추가/수정/삭제 | 승인 대기 중 수정 불가 |
| ✅ Move to Draft | Draft 상태로 되돌리기 |
| ⏳ 승인 대기 | 관리자가 검토 중 |
| ❌ 학생 등록 | 공개 전이므로 불가 |

> **참고**: 수정이 필요한 경우 "Move to Draft"로 Draft 상태로 되돌린 후 수정하세요.

### Published (공개됨)

| 액션 | 설명 |
|------|------|
| ❌ 코스 정보 수정 | 공개 중 수정 불가 |
| ❌ 레슨 추가/수정/삭제 | 공개 중 수정 불가 |
| ❌ 퀴즈 추가/수정/삭제 | 공개 중 수정 불가 |
| ✅ 학생 등록 현황 확인 | 등록된 학생 목록 조회 |
| ✅ Restore to Draft | 코스 비공개 (Draft로 전환) |

> **참고**: 공개된 코스를 수정하려면 먼저 "Restore to Draft" 후 수정하세요.

### Rejected (반려됨)

| 액션 | 설명 |
|------|------|
| ✅ 코스 정보 수정 | 제목, 설명, 가격, 썸네일 등 |
| ✅ 레슨 추가/수정/삭제 | 모든 레슨 관리 가능 |
| ✅ 퀴즈 추가/수정/삭제 | 모든 퀴즈 관리 가능 |
| ✅ Submit for Review | 수정 후 재승인 요청 |
| 📝 반려 사유 확인 | 관리자가 작성한 review_notes 확인 |
| ❌ 학생 등록 | 공개 전이므로 불가 |

> **참고**: 반려 사유(review_notes)를 확인하고 수정 후 다시 제출하세요.

## 워크플로우 예시

### 신규 코스 생성

1. **My Courses** → **Create Course** 클릭
2. 코스 정보 입력 (Draft 상태로 생성)
3. 레슨 및 퀴즈 추가
4. 삼선 메뉴 → **Submit for Review** 클릭
5. 관리자 승인 후 Published 상태로 전환

### 반려된 코스 재제출

1. **My Courses** → **Rejected** 탭에서 해당 코스 확인
2. 반려 사유(review_notes) 확인
3. 코스 수정 (Edit 버튼)
4. 수정 완료 후 삼선 메뉴 → **Submit for Review** 클릭
5. 관리자 재검토 후 승인/반려

### 공개된 코스 수정

1. **My Courses** → **Published** 탭에서 해당 코스 선택
2. 삼선 메뉴 → **Restore to Draft** 클릭
3. 원하는 내용 수정
4. **Submit for Review** 버튼으로 재승인 요청
5. 관리자 승인 후 다시 Published 상태

## 관리자 액션

| 상태 | 관리자 액션 | 결과 |
|------|------------|------|
| Pending | Approve | → Published |
| Pending | Reject (사유 입력) | → Rejected |

## FAQ

### Q: 왜 Published/Pending 상태에서 수정할 수 없나요?
**A**: 학생들이 이미 등록했거나 관리자가 검토 중인 코스의 무분별한 수정을 방지하기 위함입니다.

### Q: Rejected와 Draft의 차이는?
**A**: Rejected는 관리자가 반려한 상태로 review_notes(반려 사유)가 포함됩니다. Draft는 처음 생성되었거나 교사가 직접 되돌린 상태입니다. 둘 다 수정 가능합니다.

### Q: Unpublish하면 기존 등록 학생은 어떻게 되나요?
**A**: 기존 등록은 유지됩니다. 단, 새로운 학생은 다시 Published될 때까지 등록할 수 없습니다.

### Q: 반려 사유는 어디서 확인하나요?
**A**: Rejected 탭의 코스 카드에서 확인하거나, 코스 상세 페이지에서 review_notes를 확인할 수 있습니다.
