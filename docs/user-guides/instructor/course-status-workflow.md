# Course Status Workflow

코스의 상태 전환 및 각 상태별 가능한 액션을 설명합니다.

## 상태 다이어그램

```
┌─────────┐    Submit     ┌─────────┐    Approve    ┌───────────┐
│  Draft  │ ───────────▶ │ Pending │ ───────────▶ │ Published │
└─────────┘               └─────────┘               └───────────┘
     │                         │                         │
     │                         │ Reject                  │
     │                         ▼                         │
     │                    ┌─────────┐                    │
     └───────────────────│  Draft  │◀───────────────────┘
           (수정 후)       └─────────┘      Unpublish
```

## 상태 설명

| 상태 | 설명 | 학생 노출 |
|------|------|----------|
| **Draft** | 작성 중인 코스. 자유롭게 수정 가능 | ❌ |
| **Pending** | 관리자 승인 대기 중 | ❌ |
| **Published** | 승인 완료. 학생에게 공개됨 | ✅ |

## 상태별 가능한 액션

### Draft (초안)

| 액션 | 설명 |
|------|------|
| ✅ 코스 정보 수정 | 제목, 설명, 가격, 썸네일 등 |
| ✅ 레슨 추가/수정/삭제 | 모든 레슨 관리 가능 |
| ✅ 퀴즈 추가/수정/삭제 | 모든 퀴즈 관리 가능 |
| ✅ Submit (제출) | 관리자 승인 요청 |
| ❌ 학생 등록 | 공개 전이므로 불가 |

### Pending (승인 대기)

| 액션 | 설명 |
|------|------|
| ❌ 코스 정보 수정 | 승인 대기 중 수정 불가 |
| ❌ 레슨 추가/수정/삭제 | 승인 대기 중 수정 불가 |
| ❌ 퀴즈 추가/수정/삭제 | 승인 대기 중 수정 불가 |
| ⏳ 승인 대기 | 관리자가 검토 중 |
| ❌ 학생 등록 | 공개 전이므로 불가 |

> **참고**: 수정이 필요한 경우 관리자에게 Reject 요청 후 Draft 상태에서 수정하세요.

### Published (공개됨)

| 액션 | 설명 |
|------|------|
| ❌ 코스 정보 수정 | 공개 중 수정 불가 |
| ❌ 레슨 추가/수정/삭제 | 공개 중 수정 불가 |
| ❌ 퀴즈 추가/수정/삭제 | 공개 중 수정 불가 |
| ✅ 학생 등록 현황 확인 | 등록된 학생 목록 조회 |
| ✅ Unpublish | 코스 비공개 (Draft로 전환) |

> **참고**: 공개된 코스를 수정하려면 먼저 Unpublish 후 Draft 상태에서 수정하세요.

## 워크플로우 예시

### 신규 코스 생성

1. **My Courses** → **Create Course** 클릭
2. 코스 정보 입력 (Draft 상태로 생성)
3. 레슨 및 퀴즈 추가
4. **Submit** 버튼으로 승인 요청
5. 관리자 승인 후 Published 상태로 전환

### 공개된 코스 수정

1. **My Courses**에서 해당 코스 선택
2. **Unpublish** 클릭 → Draft 상태로 전환
3. 원하는 내용 수정
4. **Submit** 버튼으로 재승인 요청
5. 관리자 승인 후 다시 Published 상태

## FAQ

### Q: 왜 Published/Pending 상태에서 수정할 수 없나요?
**A**: 학생들이 이미 등록했거나 관리자가 검토 중인 코스의 무분별한 수정을 방지하기 위함입니다. 수정이 필요하면 Unpublish 후 진행하세요.

### Q: Pending 상태에서 급하게 수정해야 하면?
**A**: 관리자에게 연락하여 Reject 요청을 하면 Draft 상태로 돌아갑니다.

### Q: Unpublish하면 기존 등록 학생은 어떻게 되나요?
**A**: 기존 등록은 유지됩니다. 단, 새로운 학생은 다시 Published될 때까지 등록할 수 없습니다.
