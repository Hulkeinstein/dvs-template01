# Course Enrollment

코스 등록 방법 및 학습 시작 가이드입니다.

## 등록 플로우

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  코스 검색   │ ─▶ │  코스 상세   │ ─▶ │    결제     │ ─▶ │  학습 시작   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 코스 등록 방법

### 1. 코스 찾기

- **Courses** 메뉴에서 전체 코스 목록 확인
- 카테고리별 필터링 또는 검색 기능 활용
- Published 상태의 코스만 표시됨

### 2. 코스 상세 확인

코스 카드 클릭 시 확인 가능한 정보:
- 코스 제목 및 설명
- 강사 정보
- 레슨 목록 (미리보기)
- 가격

### 3. 등록하기

| 코스 유형 | 등록 방법 |
|----------|----------|
| **무료 코스** | **Enroll** 버튼 클릭 → 즉시 등록 |
| **유료 코스** | **Buy Now** 버튼 → 결제 → 등록 완료 |

### 4. 학습 시작

등록 완료 후:
1. **My Courses** 메뉴에서 등록된 코스 확인
2. 코스 클릭 → 레슨 목록 표시
3. 원하는 레슨 선택 → 학습 시작

## 학습 진행

### 레슨 완료

- 각 레슨 학습 후 **Complete** 버튼 클릭
- 진도율이 자동으로 업데이트됨
- 완료된 레슨은 체크 표시

### 퀴즈 응시

- 레슨에 포함된 퀴즈 풀이
- 점수 및 정답 확인
- 재응시 가능 (설정에 따라)

### 진도 확인

**My Courses**에서 확인 가능:
- 전체 진도율 (%)
- 완료한 레슨 수
- 남은 레슨 수

## FAQ

### Q: 등록한 코스는 어디서 확인하나요?
**A**: 상단 메뉴의 **My Courses**에서 확인할 수 있습니다.

### Q: 코스 수강 기간이 있나요?
**A**: 별도 명시가 없으면 무제한 수강 가능합니다.

### Q: 결제 후 환불이 가능한가요?
**A**: 환불 정책은 코스별로 다를 수 있습니다. 관리자에게 문의하세요.

### Q: 모바일에서도 수강 가능한가요?
**A**: 네, 반응형 디자인으로 모바일 브라우저에서도 학습 가능합니다.
